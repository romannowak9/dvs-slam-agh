# dvs_msgs

Minimal ROS message package required to deserialize `dvs_msgs/EventArray`
messages from the EvSLAM bags. The message definitions originate from the
MIT-licensed [uzh-rpg/rpg_dvs_ros](https://github.com/uzh-rpg/rpg_dvs_ros)
project. Only the two message types used by this repository are included.
